# Prism Audit — 2026-08-07

## Method

This is the first run of the autonomous improvement routine against this
repo (no prior `.prism/` memory exists, despite the app itself already
being on its 5th+ major iteration per `git log` — 50 commits, Auto Cleaner,
India Mode, PII Vault, Geo Lens, Atlas JARVIS copilot, SHAP explainability,
a full DuckDB SQL Lab, ML Lab, and more, all already shipped). Given that,
this audit is a static read-through of `app.py` (202 KB) + all 34 modules,
a clean-checkout dependency install, a headless `streamlit run` smoke test,
and a Playwright pass over the landing page and the changed tab — not a
full manual click-through of all ~15 tabs, which the mature feature set
would make disproportionately expensive for a single run. Full interactive
walkthroughs of untouched tabs are backlogged for future runs (see
`routine_log.md`).

## Findings

1. **No automated test suite existed at all** (no `tests/`, no
   `pytest.ini`, no `conftest.py`) despite 50 commits and ~200 KB of
   `app.py`. All existing quality signal came from the LLM eval harnesses
   in `eval/` (which need a live Gemini key and aren't unit tests) and the
   corpus gauntlet. This is the single biggest structural weak spot for an
   interview panel to probe ("how do you know this doesn't regress?") —
   **fixed this run**: added `tests/`, `pytest.ini`, `requirements-dev.txt`.
2. **Auto Analyst's findings are pure LLM prose with no grounding check.**
   Gemini's 5 headline findings are fluent but nothing verifies them
   against the actual data beyond having run pandas code earlier in the
   chain — a plausible-sounding but statistically empty claim (e.g. "X
   differs across Y") would display with the same confidence as a real,
   significant one. Stats Lab already has the exact machinery
   (`suggest_test`/`run_test`/`interpret_result`) to check this but the two
   modules were never connected. **Addressed this run** — see below.
3. `modules/ai_analyst.py` imports the deprecated `google.generativeai`
   SDK (`FutureWarning` on import: "All support ... has ended, switch to
   `google.genai`"). Not urgent — it still works — but a real forward-
   compat risk. Logged to backlog; out of scope for this run (SDK swap
   touches every Gemini call site, too large/risky for a single pass
   alongside a new feature).
4. `app.py` at 202 KB / one file is a genuine maintainability smell for a
   codebase this mature, but splitting it is a structural refactor, not a
   feature — explicitly out of scope per the "no architecture rewrites"
   guardrail. Logged to backlog as a proposal only.
5. No functional bugs found in the paths actually exercised (landing page,
   sample-dataset load, Overview tab, Auto Analyst tab gated state). Zero
   browser console errors, zero Python exceptions in the Streamlit log
   during the smoke test.
6. Screenshots confirm the glassmorphism system (both `prism_hud` dark and
   `arctic` light themes) renders cleanly at desktop (1280px) and mobile
   PWA widths (390px) — no overflow/clipping observed on the pages tested.

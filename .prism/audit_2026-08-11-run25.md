# Prism Audit — 2026-08-11 (Run 25)

## Scope this run

Full end-to-end feature exercise was **not** repeated from scratch — Run
24 (same day) already ran a fresh Playwright pass over the core flows and
found the app healthy (98/100 data health on sample data, zero console
errors). This run instead did a **targeted code-level audit** of the
Agent Summary / cross-detector orchestration surface, since that's where
this run's selected feature lives, plus one live pass to confirm nothing
regressed.

## Findings

1. **Confirmed via code reading**: `modules/auto_insights.py`'s
   correlation detection (`CORR_STRONG_THRESHOLD` sweep) and
   `modules/confounder_detection.py`'s stress-test both only ever compare
   **numeric-numeric** column pairs. `modules/hypothesis_sweep.py` is the
   only detector that tests categorical-vs-numeric pairs (Welch's t-test/
   ANOVA). This mattered directly for this run's feature design — see
   `.prism/research_2026-08-11-run25.md` and the routine log for the
   design pivot this caused.
2. **Minor, pre-existing, not touched this run**: uploading a plain
   ASCII/UTF-8 CSV through the sidebar occasionally triggers Prism's "This
   file wasn't valid UTF-8" fallback-encoding banner even when the file
   decodes as UTF-8 cleanly (verified independently with Python's own
   `bytes.decode('utf-8')`, which succeeds). Cosmetic/confusing in a demo
   context but harmless — the data still loads and parses correctly.
   Likely an overly-eager `chardet`/heuristic sniff on a small file rather
   than an actual mis-decode. Logged for a future run rather than fixed
   here (out of this run's scope — see Phase 6 discipline: one feature,
   don't scope-creep into unrelated fixes without budget for it).
3. **No regressions found** in the areas this run's feature touches
   (Overview tab, Agent Summary panel, Causal Effect Estimator, Stats
   Lab) — confirmed via the full pytest suite (460/460 green) and live
   Playwright verification across 4 desktop/mobile × dark/light
   combinations (see `.prism/runs/2026-08-11-run25/`).

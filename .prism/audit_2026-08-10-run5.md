## Minor UX finding (not fixed this run — backlog)

The "⋯ Advanced Tools" popover (the nav menu covering every tab except the
five primary ones) does not auto-close after clicking a destination inside
it — it stays open and visually covers the page content underneath until
the user clicks elsewhere or presses Escape. Reproducible outside Playwright
too (not an automation artifact): Streamlit's `st.popover` open/closed state
is client-side and isn't tied to the `st.rerun()` the nav button triggers.
Minor (one extra click), but a real "dead/blocking UI" pattern worth a
small fix in a future run — likely needs a workaround since `st.popover`
has no public close() API (e.g. remounting the popover via a session-state-
keyed `key=` bump on the destination change, forcing a fresh closed
instance).

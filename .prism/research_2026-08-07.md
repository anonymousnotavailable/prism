# Research — 2026-08-07

**Grounding check** (confirmed against `modules/`): Prism already has `auto_analyst.py` (LLM-prose EDA), `stats_lab.py` (manual hypothesis tests), `anomaly.py` (IsolationForest), `atlas.py` (copilot), `hellmode.py`, `india.py`. **No module currently connects Auto Analyst's LLM findings to `stats_lab.py`'s statistical tests** — confirmed gap, not just unshipped-on-paper.

## Angle 1 — Industry practice (2025-2026 interviews/JDs)
Recurring asks: A/B testing rigor (power, Type I/II error, practical vs. statistical significance), causal-inference basics (diff-in-diff, propensity matching), cohort/RFM analysis, time-series decomposition with business narration, feature importance tied to a business decision, drift monitoring. Prism covers manual stats tests, SHAP, drift already — gap is connecting statistical rigor to the *agentic* layer, not just the manual Stats Lab tab.

## Angle 2 — Competitor tools
- **Tableau Pulse**: auto-tracks metrics, detects anomalies, narrates them in plain English with drill-down suggestions — anomaly is *narrated*, not just flagged.
- **Hex/Deepnote**: inline AI trend/anomaly surfacing, next-query suggestions; assumes a coding user (lower bar than Prism's no-code UX).
- **ChatGPT Advanced Data Analysis / EDA-GPT**: writes exploratory Python, narrates findings — architecturally similar to Auto Analyst, no verification loop.
None publicly claim to run an LLM finding back through a significance test before presenting it as a conclusion — a real differentiation opening.

## Angle 3 — Ecosystem tech
Polars/DuckDB/Pandas convergence predicted as the 2026 default stack; Prism already has DuckDB via SQL Lab. PyGWalker is a standout drop-in drag-and-drop explorer but risks feeling bolted-on next to the existing dashboard builder.

## Angle 4 — Agentic EDA research
- **POPPER (arXiv 2502.09858)** — "Automated Hypothesis Validation with Agentic Sequential Falsifications": agent framework taking free-form NL hypotheses (exactly what Auto Analyst produces) through sequential statistical falsification with formal error control. Closest published blueprint for "LLM claim → statistical test → verified/rejected verdict."
- **DiscoveryBench / BLADE** — benchmarks for data-driven discovery agents, useful as design reference.
- General 2025 agent-paper pattern: critique/verify loops where a second pass checks the first agent's claims.
